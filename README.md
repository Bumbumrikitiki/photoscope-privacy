# PhotoScope policy site

This folder contains only the public PhotoScope legal pages:

- `index.html` — privacy policy (use this URL in Google Play Console)
- `terms.html` — optional Terms of Use page

## Publish with GitHub Pages

1. Create a **public** repository named `photoscope-privacy` under `Bumbumrikitiki`.
2. Upload these files from this folder to the repository root and commit them to `main`.
3. In repository **Settings → Pages**, set the source to **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. After GitHub Pages finishes deploying, the URLs should be:
   - `https://bumbumrikitiki.github.io/photoscope-privacy/`
   - `https://bumbumrikitiki.github.io/photoscope-privacy/terms.html`

The repository is separate from the Gridly website and contains no PhotoScope app source code. Verify both links load publicly before entering the privacy URL in Play Console.
